## Sobre

Tenho sólida expertise em arquitetura de sistemas, automação de processos com RPA, integração de Data Lakes e Machine Learning, além de aplicar práticas de BPM para otimização de processos e governança.

## Sobre este repositório

Site estático (HTML, CSS e JavaScript), sem etapa de build, publicado com GitHub Pages.

```text
.
├── index.html            # conteúdo em português e inglês
├── assets/
│   ├── style.css         # identidade visual
│   ├── main.js           # idioma, abas, filtro de cases e recomendações
│   └── *.jpg             # fotos
├── favicon.ico           # ícones da aba e do dispositivo
├── favicon-32.png
├── favicon-192.png
├── apple-touch-icon.png
└── .nojekyll
```

Para publicar: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.
